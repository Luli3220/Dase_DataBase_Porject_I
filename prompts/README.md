# 开发规格与Prompt索引

本目录保存项目负责人提供的原始开发规格，正文保持不变。课程原始要求另见 [project1.pdf](../requirements/project1.pdf)。

按以下顺序阅读：

1. [00 — 总控Prompt](00-总控Prompt.md)：实施顺序、总体约束和阶段验收。
2. [01 — 数据库与规则引擎](01-数据库与规则引擎.md)：MongoDB模型、版本、匿名、重复策略、规则语义。
3. [02 — 后端API与网页](02-后端API与网页.md)：认证、权限、API和网页交互。
4. [03 — 测试文档与验收](03-测试文档与验收.md)：测试、证据、交付文档和完成标准。

辅助资料：[完整合并Prompt](完整实施Prompt.md)、[最初规格导读原文](original-specification-readme.md)。

原文中的文件位置对应最初开发目录；整理后，PDF位于requirements/，实现位于source/，交付文档位于docs/。提示中的app、scripts、tests等实现路径均对应当前source下的目录。实际运行说明以 [source/README.md](../source/README.md) 为准，开发规格不是测试结果或完成报告。
