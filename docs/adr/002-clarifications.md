# 业务约定

以下约定将课程中的功能描述落实为具体的数据和接口行为。

|主题|约定|
|---|---|
|题型|填空分为text和number，连同单选、多选构成四种内部类型|
|匿名|填写者先登录，系统内部保存respondentId；创建者看到的身份由每次提交的anonymousAtSubmission决定|
|重复填写|每次新填写追加记录，latest_only影响有效统计，历史记录继续保留|
|跨版本统计|先在整份问卷中确定每人的最新提交，再筛选目标版本|
|策略锁定|首份成功提交在事务中设置hasSubmissions，之后固定submissionPolicy|
|发布恢复|先冻结版本再切公开指针；中断后沿用原revision重试|
|关闭后的幂等重试|成功请求可以再次查询到原结果，新逻辑提交按关闭状态拒绝|
|请求内容|摘要按questionId排序后计算，保留原始值；重试沿用同一UUID与body|
|数值范围|有限JSON数字，绝对值不超过2^53-1；布尔和数字字符串属于非法类型|
|标题与说明|由surveys管理；题目和匿名设置随survey_versions保存|
|退出登录|递增users.sessionVersion，使该账号已有会话失效|
|统计快照|同一次统计或列表响应使用snapshot事务，后续提交通过刷新获取|
|联合保存|元信息、草稿修订和来源检查在同一事务中提交；单独编辑仍可使用原接口|
|题目来源|全局身份和精确版本用于复用与统计，局部ID用于本卷路由和答案|
|题目共享|被共享者可读取和复用，独立维护使用fork|
|版本恢复|复制旧内容追加版本，并记录恢复来源|
|归档选题|选择器先按activeOnly过滤归档，再分页与计数；管理页查看全部题目|
|跨问卷统计|按精确题目版本汇总，外部数据由问卷所有者授权贡献|
|统计问卷数|surveyCount是当前口径下有提交参与的去重问卷数；usage.total是可见版本引用条数|

具体字段见[数据库设计](../database-design.md)，请求与错误语义见[API文档](../api.md)。
