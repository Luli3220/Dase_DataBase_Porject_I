# ADR 002：原始要求、规格歧义和实现澄清

原始PDF十一页已完整阅读，课程要求没有删减。后续规格明确的匿名/版本/重复口径优先解释原始需求的未定义部分。

|问题/冲突|处理与理由|风险与第二阶段影响|
|---|---|---|
|“可以在conda db操作”而db为Python3.10.21，规格要求3.11+|使用已有Python3.11.5创建项目隔离venv，不修改用户原环境|setup支持指定解释器；可迁到新的3.11 conda环境|
|PDF三类题，填空包括文本与数字|内部拆成四种type，完整涵盖原要求|新增填空类型继续扩展分派|
|PDF匿名与“填写必须先登录”|匿名只隐藏创建者可见账号，内部保留respondentId去重|不能保证自由文本绝对不可识别|
|“每次填写都保存”与latest_only|每次追加；latest_only只影响有效统计，不覆盖历史|统计始终声明mode/version|
|Q3样例“否则END”与通用默认下一题|样例添加lt10/end规则，gte10/q4在前；默认算法始终下一题|避免问卷ID或题目路径硬编码|
|首份成功后策略锁定与并发修改|副本集事务内写hasSubmissions、共享writeRevision|需要replica set，单卷写热点见ADR001|
|发布先冻结后指针中断|draft指向sealed作为可检测待恢复状态，同revision重试publish|冻结后不可编辑，所有者需完成发布或保持关闭|
|关闭后相同请求重试|允许返回已成功记录，仅禁止新逻辑提交|不增加关闭后新答卷；避免网络丢响应时误报失败|
|“相同请求内容”的定义|摘要对原始答案按题ID排序，保留值；空白或选项顺序变动可算不同内容|浏览器保留锁定body，未来可引入更宽松规范化但要兼容旧键|
|数字范围与浏览器/BSON差异|绝对值≤2^53-1，拒绝bool/非有限；先判范围避免极大整数转换溢出|真实手机号使用文本更合适，课程整数例仍支持|
|标题/说明未进入版本字段|遵守既定surveys存元信息；题目/匿名内容快照不可变|历史题目可解释，但问卷标题显示当前元数据，若要历史标题需新schema扩展|
|退出Cookie可能被复制重放|users增加sessionVersion，退出撤销该账号全部旧会话|多设备同时退出，未加第五集合|
|统计多查询与提交并发|同次统计/列表用只读snapshot事务|不同HTTP请求之间仍可能不同快照|

未选择：关系数据库（课程禁止）；将题目/选项机械拆集合（破坏版本快照边界）；匿名删除系统身份（无法去重）；按版本先过滤再去重（旧版本错误复活）；允许回跳（增加循环与路径语义）；将原始JSON编辑作为主要UI（不满足可用表单编辑要求）。Docker配置提供但因本机daemon不可用不声称运行验证；本机真实Mongo替代实现不改变数据库类型。
